## C. 性能测量方法

1. 用含 200 项书签的测试配置，独立 Chrome profile（`--user-data-dir`）。
2. DevTools → Performance，新建标签页后录制；记录首次可交互时间（可交互 = 卡片可点击）。
3. 记录 DOM 节点数与首屏渲染耗时；对比 `pnpm build` 产物（非 dev 产物）。
4. 结果写入 ACCEPTANCE.md 的验证段。
